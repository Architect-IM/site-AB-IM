# Сайт Ирины Михейкиной

Совместный репозиторий Ирины и Михаила.

## Совместная работа

- [Порядок работы в ветках и просмотра изменений](docs/COLLABORATION.md)
- [Первое подключение Михаила в Grok Build](docs/GROK-START.md)
- [Все предпросмотры сайта](https://architect-im.github.io/site-AB-IM/)

Общий источник актуального сайта — `main`, папка `sites/irina-architecture`.
Ирина работает в `irina/*`, Михаил — в `mihail/*`. Изменения проходят проверку и
согласование через pull request. Основной сайт в Sites публикуется отдельно из
согласованной версии. Подключение внутри аккаунта Grok подтверждается после
успешного получения общей версии и отправки ветки самим Михаилом.

### С чего начать вдвоём

1. Михаил копирует первое сообщение из [инструкции для Grok Build](docs/GROK-START.md) в свой чат и проверяет получение `main`, запуск сайта и отправку своей ветки.
2. Ирина открывает [общую версию](https://architect-im.github.io/site-AB-IM/main/), [свои правки](https://architect-im.github.io/site-AB-IM/irina/) или [правки Михаила](https://architect-im.github.io/site-AB-IM/mihail/). До первой правки личные версии одинаковы.
3. Для проверки изменений открыть [Pull requests](https://github.com/Architect-IM/site-AB-IM/pulls), перейти по ссылке предпросмотра в комментарии и дождаться зелёного `site-checks`. Второй участник выбирает **Files changed → Review changes → Approve** либо оставляет замечания. После одобрения можно объединить изменения кнопкой **Merge pull request**.

Подробный порядок и готовое задание для Ирины — в [памятке совместной работы](docs/COLLABORATION.md).

## Актуальный сайт — Sites

Исходники опубликованного сайта находятся в **[sites/irina-architecture](sites/irina-architecture)**.

- Сайт: https://irina-mikheykina-architecture.miheikina-iv.chatgpt.site
- Перенесённая версия Sites: **52**, опубликована 4 октября 2026 года.
- Исходный коммит Sites: `33809f17ecd0d0473f1245e80999116a25d2f2a9`.
- Включены все страницы и изображения, страница «Консалтинг», «Владимирский контекст» и четыре подробных описания его услуг.

### Запуск

Требуются Node.js 22.13 или новее и pnpm 11.25.0. Команды выполняются из папки актуального сайта:

```sh
cd sites/irina-architecture
corepack pnpm install --frozen-lockfile
corepack pnpm dev
```

Если Corepack не установлен, используйте установленный pnpm 11.25.0 вместо `corepack pnpm`.

Проверка типов и сборка:

```sh
corepack pnpm exec tsc --noEmit --incremental false
corepack pnpm build
```

Рабочая копия открывается по адресу, который команда `dev` выводит в терминал.

GitHub хранит общую согласованную версию. Предпросмотры публикуются автоматически, основной сайт в Sites — отдельно по запросу Ирины из `main`. Порядок синхронизации описан в [инструкции](docs/COLLABORATION.md).

Форма контактов открывает почтовое приложение с подготовленным письмом; отдельного сервера отправки писем нет.
