# Дизайн-система сайта  
**Архитектурное бюро Ирины Михейкиной**

**Статус:** утверждённая основа (десктоп — макет «Дизайн сайта», 25.08.2026; мобильный стандарт — 10.09.2026)  
**Применение:** все страницы сайта (портфолио проектов, услуги, подход, о бюро, контакты и др.)

## 2. Типографика

### Основные шрифты (рекомендуемые веб-аналоги)
- **Заголовки и UI:** современный геометрический / гуманистический sans-serif  
  (близко к: Inter, Manrope, Geist, или системный `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`)
- **Цитаты и акцентная подпись:** более элегантный, с лёгким контрастом  
  (можно использовать тот же sans с увеличенным letter-spacing / light weight, либо тонкий serif для цитат)
- **Подпись «Ирина Михейкина»:** рукописный / script стиль (как на макете)

### Иерархия

| Элемент                      | Размер (desktop) | Weight     | Tracking / Особенности          | Цвет          |
|------------------------------|------------------|------------|----------------------------------|---------------|
| Hero-заголовок               | 48–64 px        | SemiBold / Bold | −1…−2 %                         | Белый        |
| Hero-подзаголовок            | 18–20 px        | Regular    | нормальный                       | Белый 85%    |
| Навигация                    | 13–14 px        | Medium     | +2…+4 % uppercase                | Белый / тёмный |
| Section title (КЛЮЧЕВЫЕ ФАКТЫ и т.п.) | 13–14 px | Medium     | +8…+12 % uppercase               | Тёмный       |
| Заголовок блока (Задача, Решение…) | 22–28 px   | SemiBold   | нормальный                       | Тёмный       |
| Body text                    | 16–17 px        | Regular    | line-height 1.55–1.65            | Тёмный       |
| Цитата («Взгляд Ирины»)      | 20–24 px        | Light / Regular | увеличенный line-height        | Тёмный       |
| Подпись к цитате / роли      | 13–14 px        | Regular    | +2 %                             | Вторичный    |
| Ключевые факты (значение)    | 15–16 px        | Medium     | —                                | Тёмный       |
| Ключевые факты (лейбл)       | 11–12 px        | Regular    | +4 % uppercase                   | Вторичный    |
| CTA-ссылки                   | 13–14 px        | Medium     | +2 % + стрелка →                 | Тёмный + акцент |

**Правило:** все section titles — UPPERCASE + увеличенный letter-spacing.  
Основной текст никогда не меньше 16 px на desktop и на мобильном.

## 3. Компоненты и паттерны (уже есть на макете)

### 3.1. Хедер
- Тёмный фон / прозрачный на hero
- Слева: логотип (геометрический знак + «АРХИТЕКТУРНОЕ БЮРО ИРИНЫ МИХЕЙКИНОЙ»)
- Справа: горизонтальное меню (О БЮРО · ПРОЕКТЫ · УСЛУГИ · ПОДХОД · КОНТАКТЫ) + переключатель языка
- Минимальный, без лишних элементов

### 3.2. Hero-блок (проект)
- Полноширинное фото архитектуры
- Тёмный градиентный оверлей слева
- Крупный заголовок + короткий подзаголовок
- CTA «СМОТРЕТЬ ПРОЕКТ →»

### 3.3. Ключевые факты
- Горизонтальный ряд из 4–5 пунктов
- Иконка (линейная, цвет акцента) + лейбл (uppercase) + значение
- Разделители — тонкие вертикальные линии акцентного цвета или просто воздух

### 3.4. Блок «Взгляд Ирины»
- Фото Ирины (портрет / полуфигура) слева
- Крупная цитата справа
- Подпись с именем и ролью
- Рукописная подпись «Ирина Михейкина» как акцент

### 3.5. Решение / Результат
- Две колонки
- Заголовок + текст + маленькое фото + CTA «ПОДРОБНЕЕ… →»

### 3.6. Нижняя полоса продуктов
- Горизонтальный список тегов/продуктов с иконками
- Лёгкий разделитель сверху
- Используется как «хлебные крошки» компетенций проекта

### 3.7. Общие элементы
- Тонкие золотистые горизонтальные линии-разделители
- Стрелки в CTA всегда `→`
- Иконки — тонкие line-icons в цвете акцента
- Скругления: минимальные или отсутствуют (современная архитектурная строгость)
- Большие поля и воздух между блоками

## 4. Принципы, которые фиксируем

1. **Тёплый минимализм** — никакого визуального шума.
2. **Архитектура на первом плане** — фото всегда качественные, крупные, с характером.
3. **Ирина как лицо** — блок «Взгляд Ирины» и её фото/подпись присутствуют на ключевых страницах проектов.
4. **Структура портфолио** (уже утверждена ранее):
   - Название + смысловой подзаголовок
   - Ключевые факты
   - Задача заказчика
   - Взгляд Ирины / Ключевой ход
   - Решение
   - Результат
   - Что это показывает в Ирине
   - Визуальный ряд + участники
5. **Акцент на смысле**, а не на декоре. Золото — только для навигации взгляда и лёгких акцентов.

## 5. Мобильный стандарт (утверждён 10.09.2026)

Мобильная страница проектируется **с чистого листа**, а не как сжатый десктоп. Те же цвета, шрифты и смысл блоков — другая композиция.

### 5.1. Принципы
1. Только одна колонка. Никаких 2–5 колонок и панорамных баннеров.
2. Фото — вертикальные (3:4) или квадратные (1:1). Горизонтальные панорамы на телефоне не используем.
3. Текст и изображение почти никогда не стоят рядом: сначала одно, потом другое.
4. Воздух по вертикали важнее плотности. Экран читается как статья, а не как витрина.
5. Навигация — логотип + бургер. Горизонтальное меню на мобайле не показываем.

### 5.2. Хедер
- Компактная тёмная полоса
- Слева: знак + короткое слово
- Справа: иконка меню
- Можно закреплять при скролле

### 5.3. Hero проекта
- Высокий вертикальный кадр объекта на всю ширину
- Заголовок и подзаголовок — **под** фото, на тёмном или светлом блоке
- Не класть длинный текст поверх широкого фасада

### 5.4. Ключевые факты
- Вертикальный список из 5 строк
- Строка: линейная золотая иконка + лейбл (uppercase) + значение
- Не ряд из пяти колонок

### 5.5. Задача заказчика
- Заголовок + короткий абзац + маркированный список
- Без бокового фото

### 5.6. Взгляд Ирины
- Сначала полноширинный портрет (4:5 или квадрат)
- Затем цитата крупным кеглем
- Затем рукописная подпись
- Не layout «фото слева / текст справа»

### 5.7. Решение и Результат
- Идут друг за другом, не в две колонки
- В каждом блоке: заголовок → текст → одно квадратное/вертикальное фото

### 5.8. Что это показывает
- Две карточки одна под другой: «Для Ирины» / «Для бюро»

### 5.9. Продукты
- Плашки-чипы в 1–2 колонки с переносом
- Не одна горизонтальная лента, которую надо скроллить вбок (допустим только как исключение)

### 5.10. Галерея
- Сетка 2×2 из квадратов
- Либо вертикальный стек крупных кадров
- Без широких пейзажей

### 5.11. Съёмка под мобайл
На этапе режиссуры фото сразу закладывать:
- вертикальный фасад / угол здания
- портрет Ирины на объекте
- квадратный интерьер-деталь
- квадратное «окно-иллюминатор» / фрагмент производства
- квадрат территории / геопластики
