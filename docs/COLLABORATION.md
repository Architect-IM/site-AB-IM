# Как вместе править сайт

## Общая основа

Мы работаем в одном репозитории: https://github.com/Architect-IM/site-AB-IM.

Актуальный сайт находится в `sites/irina-architecture`. Оба помощника редактируют эту папку. Корневая папка `src/` относится к прежней версии Grok.

| Участник | Помощник | Ветки |
| --- | --- | --- |
| Ирина | ChatGPT/Codex | `irina/*` |
| Михаил | Grok на grok.com, режим Build | `mihail/*` |
| Общая версия | Согласованные правки обоих | `main` |

Стартовые ветки — `irina/work` и `mihail/work`. Для отдельных задач удобнее создавать ветки `irina/contacts`, `mihail/portfolio` от последней `main`.

## Каждая задача

1. Получить последние изменения `main` и прочитать инструкции репозитория.
2. Сделать правки в своей ветке внутри `sites/irina-architecture`.
3. Проверить сайт и отправить ветку в GitHub.
4. Открыть pull request в `main`, описать изменения.
5. Дождаться `site-checks` и публикации предпросмотра. Проверка собирает обычный сайт, затем отдельную статическую копию для просмотра.
6. Другой участник открывает предпросмотр, пишет замечания или выбирает **Approve** в GitHub. После изменений помощник отправляет новые коммиты в тот же PR.
7. Когда проверка прошла и получено одобрение, объединить PR. Перед следующей задачей снова получить свежую `main`.

Ветки не обновляют друг друга автоматически. Git объединяет правки при слиянии. Если оба изменили одно место, помощник должен показать конфликт и согласовать итоговый вариант.

## Как смотреть результат

Общий список копий: https://architect-im.github.io/site-AB-IM/.

- `main/` — согласованная общая версия.
- `irina/` — последнее успешно проверенное изменение из веток Ирины.
- `mihail/` — последнее успешно проверенное изменение из веток Михаила.
- `pr-N/` — отдельная копия конкретного PR, например `pr-3/`.

Ссылка появляется в комментарии GitHub Actions к PR. Под ней указан проверенный коммит. После отправки новых правок дождитесь обновления этой записи. Пока проверки идут, ссылка может показывать предыдущий успешный вариант.

Репозиторий и предпросмотры общедоступны. В предпросмотры попадает код сайта и его общедоступные материалы. Они помечены `noindex`; это не ограничение доступа.

В предпросмотре работают страницы, меню, фильтры и подготовка письма в контактах. Это статическая копия; если позже добавятся серверные функции, для них понадобится отдельный способ проверки.

## Основной сайт в Sites

Рабочий адрес: https://irina-mikheykina-architecture.miheikina-iv.chatgpt.site.

Предпросмотры публикуются автоматически. Основной сайт в Sites публикуется отдельно из согласованной `main` по запросу Ирины, например:

> Опубликуй согласованную версию main из Architect-IM/site-AB-IM в нашем существующем сайте Sites. Сначала проверь, нет ли несохранённых изменений в Sites.

Публикующий помощник должен получить последние исходники GitHub и Sites, проверить различия, сохранить идентификатор существующего Site и выполнить обычную публикацию Sites. Если в Sites появились отдельные правки, сначала перенести их в ветку GitHub и согласовать.
